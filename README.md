# LangSwitch

Утилита в трее. Права администратора не нужны.

- Переключает язык по настраиваемой горячей клавише (по умолчанию `Ctrl+Shift`).
- Конвертирует последнее слово по двойному нажатию клавиши (по умолчанию `Shift`): стирает его, переключает раскладку и набирает те же клавиши заново (`ghbdtn` → `привет`). Повторное двойное нажатие возвращает исходный текст.
- Если после перемещения курсора (клик, стрелки, Ctrl+A) ничего не набрано, двойное нажатие конвертирует **выделенный текст**: копирует его через буфер обмена, переводит по раскладкам системы и вставляет обратно. Содержимое буфера обмена потом восстанавливается во всех форматах (картинки, файлы и т.п.) на Windows и macOS; на Linux — только текст. Временные данные не попадают в журнал буфера обмена Windows (Win+V) и в менеджеры истории на macOS.
- Конвертирует **всю фразу** — текст, набранный после последнего перемещения курсора: тройным нажатием клавиши конвертации или двойным нажатием отдельной клавиши (выбирается в настройках).
- **Исключения:** в выбранных приложениях (по имени исполняемого файла, например `mstsc.exe`) программа ничего не делает. Приложение можно вписать вручную или нажать «Выбрать приложение» и нажать любую клавишу в нём.
- **Проверка обновлений** через GitHub Releases раз в сутки: о новой версии сообщает уведомление и пункт в меню трея. Версия сборки берётся из git-тега (`make build`).
- Каждую функцию можно отключить в настройках.

- Автозапуск при входе в систему (галочка в настройках): Windows — `HKCU\Software\Microsoft\Windows\CurrentVersion\Run`, macOS — `~/Library/LaunchAgents/io.github.langswitch.plist`, Linux — `~/.config/autostart/langswitch.desktop`. Если переместить исполняемый файл, галочку нужно включить заново.

Настройки хранятся в `<UserConfigDir>/langswitch/config.json`.

Иконка рисуется командой `go run ./tools/genicon` в `assets/icon.png`, упрощённая иконка трея — `go run ./tools/genicon -tray` в `assets/tray.png`; на Windows из неё же собирается ресурс exe (`rsrc_windows_amd64.syso`, утилита `go-winres`). `make build` делает это автоматически, `make icon` — перерисовать.

## Установка

Готовые сборки — на странице [Releases](https://github.com/nailspb/langswitch/releases/latest):

- **Windows:** `langswitch-windows-amd64.exe` — запустить, установка не нужна.
- **macOS:** `langswitch-macos-universal.zip` — распаковать `LangSwitch.app` в «Программы». Приложение не нотаризовано, поэтому при первом запуске: правый клик → «Открыть», либо `xattr -dr com.apple.quarantine /Applications/LangSwitch.app`.
- **Linux (X11):** `langswitch-linux-amd64.tar.gz` — нужны `libxtst6` и `libxkbcommon0`, glibc 2.35+.

Релиз собирается GitHub Actions автоматически при пуше тега `v*`:

```bash
git tag v0.2.0 && git push origin v0.2.0
```

## Сборка

Fyne требует CGO, поэтому нужен компилятор C.

```bash
go mod tidy
```

| ОС | Зависимости | Сборка |
|---|---|---|
| Windows | gcc (MSYS2 mingw-w64 или WinLibs) | `go build -ldflags "-H windowsgui" -o langswitch.exe .` |
| macOS | `xcode-select --install` | `go build -o langswitch .` |
| Linux | `gcc libgl1-mesa-dev xorg-dev libxtst-dev libxkbcommon-dev` | `go build -o langswitch .` |

## Ограничения

- **Windows:** не работает в окнах, запущенных от администратора (так устроен UIPI). Если такое же сочетание задано в системе, отключите его там, иначе язык переключится дважды.
- **macOS:** при первом запуске нужно выдать разрешение «Универсальный доступ» и перезапустить программу. Чтобы убрать значок из Dock, соберите приложение через `fyne package` и пропишите `LSUIElement` в Info.plist.
- **Linux:** работает только в X11, Wayland не поддерживается. Нажатия не поглощаются, поэтому `CapsLock` в роли горячей клавиши будет ещё и включать заглавные буквы. Лучше выбрать сочетание из модификаторов. В GNOME раскладкой управляет сама оболочка и может сбрасывать переключение.
